🟢 구글 스프레드시트 실시간 연동 설정

부부가 동일한 구글 시트를 연동하면, 어디서든 실시간으로 지출/수입 내역을 함께 기록하고 공유할 수 있습니다!

연동 상태: 미연동 (로컬 저장소 사용 중)
🔍 구글 앱스 스크립트(Google Apps Script) 생성 3단계 가이드
  1. 구글 스프레드시트에서 새 시트를 생성합니다.
  2. 상단 메뉴 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
  3. 기존 코드를 지우고 아래 제공된 스크립트 코드를 붙여넣은 후 저장(Ctrl+S)합니다.
  4. [배포] ➔ [새 배포] ➔ 톱니바퀴[유형 선택] ➔ [웹 앱] 선택 후 액세스 권한 있는 사용자: '모든 사용자(Anyone)'로 배포합니다.
  5. 생성된 웹 앱 URL(Web App URL)을 위 입력란에 복사하여 붙여넣고 [연동 테스트 및 저장]을 누릅니다.
